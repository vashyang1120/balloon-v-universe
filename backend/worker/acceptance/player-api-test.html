步驟 4：限流檢查（只讀，不寫入資料）

目標：確認「找回＋讀取」的限流（每個 IP 每分鐘約 300 次）在正式環境有作用。
做法：同時保持 8 個請求、快速送出「讀取一個格式正確但不存在的玩家」（只讀資料庫，不會建立任何資料）， 最多 400 次；出現第一次 429 後再送 20 次就自動停止。全程應在 60 秒內完成，否則結果不能判斷。
注意：做完後這台裝置的網路約 1 分鐘內無法找回玩家（同一個 IP 的額度用完了），屬正常現象。
