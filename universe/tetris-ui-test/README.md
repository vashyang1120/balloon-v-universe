## 桌機播放器修正 v0.3.2-test-2

基準：PR #34 合併後 `c217b8f`。使用者截圖顯示桌機右側播放器第四顆「播放清單」按鈕超出螢幕。原因為原 `.side` 最寬 130px，扣除側欄及播放器內距後只剩 92px，四顆按鈕的 intrinsic 寬度總和超出。

只新增 `desktop-ui.css`，所有規則限定 `html.uit-brand:not(.uit-m)`：畫面水平內縮 16–32px、左右側欄加寬至 168–192px 並使用同寬 flex basis，播放器按鈕改四等分 minmax(0,1fr)，保留 32px 最小高度。棋盤維持兩側等寬下的水平置中。手機配置、操作、音樂播放、教學／故事、正式版與資料皆不改。版本 UI v0.3.2-test-2，新增樣式及版本腳本附快取版本碼。

既有 52 項檢查及建置可重現驗證；此環境無法啟動本機 Chromium，未宣稱已實測桌機 CSS 邊界。部署後以 1920×936（回報尺寸）、1366×768、1024×768 驗收四顆按鈕完整在框內及畫面內，上一首／播放／下一首／清單功能正常；手機仍維持原配置。

## 電腦首頁音樂修正 v0.3.1-test-2
