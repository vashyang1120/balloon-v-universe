# Batch 2-B Test 2｜音樂舞台音響驗收

## 基準與範圍

以使用者確認外側音響震動幅度及節奏的 Batch 2-B Test 1 為基準，父提交為 `9de3cde2d84f17467cec0ea53cbe7b768670c386`。本版補上舞台拱門兩側的內側音響，四組使用同一套既有節奏。全場底稿仍為 Integration Preview Test 2，包含已驗收的 Batch 2-A Test 2 瀑布。正式入口維持原部署。

## 結構調查與實作

| 組別 | 原圖工作區 x、y、寬、高 | 箱腳錨點 x、y | 節奏 |
| --- | --- | --- | --- |
| 左外側音響與頂星 | 1009、200、59、108 | 1039、302 | 左音符主拍 |
| 右外側音響與頂星 | 1302、232、57、115 | 1329、340 | 右音符主拍 |
| 左內側音響 | 1066、215、51、85 | 1092、293 | 左音符主拍 |
| 右內側音響 | 1265、232、39、90 | 1287、313 | 右音符主拍 |

四組音響直接擷取自 1536×1024 原始地圖。外側音響與頂星各共用一張透明圖。內側遮罩保護箱腳前的裝飾與拱門，右內側音響靠外箱的一線交界固定。箱體移動露出的窄邊從輪廓附近的原圖修補，取樣上限約 3 px。放大位移前應重新檢查遮擋與底圖。

音響直接讀取既有音符的 0.84 秒週期、0.32 秒接拍間隔及回彈曲線。主拍最高橫向 3.5%、縱向 3.1%，另一側同時收到 68% 的動量。微量左右斜切以箱腳為基準，休止時回到原像素。沒有新增音效。

## 驗收紀錄

- 桌面 Chrome 與 Pixel 7 模擬開啟 HTML、放大比較、播放及開關正常。18 個取樣時點內，四組遮罩外的像素及全場 Alpha 差異皆為 0。固定 Chrome 2D 後端用於逐像素測試。
- 左右主拍的四組音響與外側頂星均有像素位移。以相同的圖層初始狀態比對新增內側音響前後，兩個主拍的內側遮罩之外逐像素一致。休止與循環端點回到原像素。
- 全場既有 Chrome 測試複驗，涵蓋熱氣球、旗幟、音符、氣球束、角色互動與賊鷗。瀑布獨立開關另行複驗，方塊區主瀑布與 Batch 2-A Test 2 的原始樣本逐像素一致。
- 本次以 Chrome 手機模擬驗證。手機實機與正式入口的端到端測試未執行。待使用者視覺驗收。
