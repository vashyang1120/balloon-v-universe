# Integration Preview Test 2｜瀑布全場整合交接

## 基準與修改範圍

使用 2026-11-22 通過驗收的 Integration Preview Test 1（surprise）作全場基準，採用同日通過驗收的 Living Lobby Art v1.0｜Batch 2-A Test 2 作瀑布主樣本。方塊區主瀑布的位移、流速、亮紋、水花與波紋逐幀沿用。

| 原圖區域 | 本版動態 |
| --- | --- |
| 方塊區主瀑布 | 沿用 Test 2 的四段流水、原有水花及水面 |
| 方塊區外側細瀑布 | 左崖細流 |
| 左上浮島 | 遠景白藍直流 |
| 右上遠景城堡島 | 紫粉及藍色可辨識水帶 |
| 左下花圃浮島 | 崖面細流 |
| 音樂舞台下方 | 植栽間隔的兩段可見水流 |
| 右側船後 | 小瀑布兩段水紋 |
| 右側船區主瀑布 | 主水流、原有水花與相連水面 |
| 中央廣場右下橋旁 | 水柱、原有水花與相連水面 |

9 處瀑布群以 10 塊局部遮罩實作。流速與亮紋強度依可見寬度、景深與遮擋調整。近景用同一套局部位移和亮度演算法，遠景保留較輕的變化。中央噴泉在本批瀑布範圍之外。

原始地圖與完整已驗收資產逐檔沿用，水紋在既有場景背景上疊入，再繪製熱氣球、旗幟、音符等前景。預覽繪製順序、開關與已驗收互動及角色演出均可查看新增程式和對照結果。純原圖重設模式仍顯示原始地圖。正式遊戲入口與正式發布流程維持原狀。
