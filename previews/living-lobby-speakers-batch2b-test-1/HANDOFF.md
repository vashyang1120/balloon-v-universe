# Batch 2-B Test 1｜音樂舞台音響驗收

## 基準與範圍

正式美術基準為 2026-11-22 確認的 Integration Preview Test 1。本批使用後續 Integration Preview Test 2 的獨立副本，保留已驗收的 Batch 2-A Test 2 瀑布與全場擴充。兩版的原圖及共用動畫資產 SHA-256 均一致。Git 的父檔案版本取自瀑布整合分支 `81802634c7a7d1c930add778498baa5dfcefddec`。正式入口、部署及已驗收成果由原版本持有。

## 結構調查與實作

| 組別 | 原圖工作區 x、y、寬、高 | 箱腳錨點 x、y | 節奏 |
| --- | --- | --- | --- |
| 左外側音響與頂星 | 1009、200、59、108 | 1039、302 | 左音符主拍 |
| 右外側音響與頂星 | 1302、232、57、115 | 1329、340 | 右音符主拍 |

音響與頂星原本畫在同一張 1536×1024 地圖，頂星與箱體直接接觸。每組以同一張透明圖擷取，原始像素用於運動圖層。箱腳前的裝飾和右箱左鄰以獨立遮罩保護。箱體移動露出的窄邊以輪廓外側的鄰近原圖像素修補，取樣上限約 3 px。修補圖是為本次微幅震動設計，若日後放大位移，需要重查遮擋和底圖。

音響直接讀取既有音符的 0.84 秒週期、0.32 秒接拍間隔及回彈曲線。主拍最高橫向 3.5%、縱向 3.1%，另一側同時收到 68% 的動量。微量左右斜切以箱腳為基準，休止時回到原像素。沒有新增音效。

## 驗收紀錄

- 桌面 Chrome 與 Pixel 7 模擬開啟 HTML、放大比較、播放及開關正常。18 個取樣時點內，兩組遮罩外的像素及全場 Alpha 差異皆為 0。固定 Chrome 2D 後端用於逐像素測試。
- 兩次主拍皆觀察到兩側音響及兩顆星星連動。休止和循環端點回到同一組像素。近景逐幀檢查未見明顯接縫、殘影或錯位。
- 全場既有 Chrome 測試複驗，涵蓋熱氣球、旗幟、音符、氣球束、角色互動與賊鷗。瀑布獨立開關另行複驗，方塊區主瀑布與 Batch 2-A Test 2 的原始樣本逐像素一致。
- 本次以 Chrome 手機模擬驗證。手機實機與正式入口的端到端測試未執行。待使用者視覺驗收。
