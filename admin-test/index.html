Firebase UID

UID 是你在這個 Firebase 專案的帳號編號，不是密碼。只有 UID 也無法登入或取得管理權限。為了安全，關閉或重新整理這個分頁就會自動登出。

2管理員權限（由伺服器判斷）

登入後會自動向伺服器確認

把你的 UID 設定成管理員：

  1. 按上面的「複製 UID」。
  2. 開 Cloudflare → Workers & Pages → balloon-v-universe-api → Settings → Variables and Secrets。
  3. 按「Add」，Type 選 Secret，Name 填 ADMIN_UIDS，Value 貼上 UID，儲存。
  4. 回到這頁按「重新確認權限」。

3測試 Firebase 連線（只讀）

伺服器確認你是管理員後才能測試

這個測試只會「讀取」資料庫中一個固定的測試位置，不會新增、修改或刪除任何資料。資料庫目前是空的，讀到「空（null）」是正常的。
